The World in One Day — Thursday 26 November 2026. A program that draws a
one-page news broadsheet summing up 26 November 2026's world news: the
Houthi strike on Saudi Arabia's Ras Tanura refinery, US tariffs on 14
trading partners, Pakistan's first astronaut aboard China's Tiangong
station — plus 23 more stories across five regions, with a by-the-numbers
strip and a date check.

## Run it

```sh
python3 main.py
```

Writes the image to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`
when set). No network, standard library plus Pillow, deterministic: two
runs produce identical bytes.
